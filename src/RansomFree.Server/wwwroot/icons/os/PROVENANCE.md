# Operating-system icons

Bundled, unmodified SVG artwork from Font Awesome Free 6.7.2 by Fonticons, Inc.
Source commit: `af620534bfc3c2d4cbefcfeec29603bbe7809e64`.

- Windows: https://github.com/FortAwesome/Font-Awesome/blob/af620534bfc3c2d4cbefcfeec29603bbe7809e64/svgs/brands/windows.svg
- Linux: https://github.com/FortAwesome/Font-Awesome/blob/af620534bfc3c2d4cbefcfeec29603bbe7809e64/svgs/brands/linux.svg
- Apple (macOS identification): https://github.com/FortAwesome/Font-Awesome/blob/af620534bfc3c2d4cbefcfeec29603bbe7809e64/svgs/brands/apple.svg

SVG icons: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/ . Full upstream license and required comments are retained in this directory. Font Awesome: https://fontawesome.com . Third-party trademarks belong to their owners; use identifies the endpoint OS and does not imply endorsement. No remote request is needed at runtime. No watermarked stock reference was used.

Status graphics and the neutral unknown-OS symbol are original application SVG/CSS, not Font Awesome or copied reference artwork. Filled green circle/check = healthy; filled yellow circle/exclamation = warning; filled red circle/X = failed; filled gray circle/question = unknown. There is no decorative filled/outline state variation. Every icon has an accessible text label, title and focus/hover tooltip; Escape dismisses the tooltip.

OS comes only from the authenticated endpoint's explicit operatingSystem report. Legacy/unreported OS is unknown, not guessed from hostname, version, or a Linux distribution assumption. Reports say Linux, not a specific distro. Metadata is identification evidence, not attestation or proof of current protection.
